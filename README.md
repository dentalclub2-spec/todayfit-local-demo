# 오늘도핏 로컬 문의 데모

가상의 헬스장 랜딩 페이지와 관리자 문의 목록을 같은 브라우저의 `localStorage`로 시험하는 정적 데모입니다. 실제 개인정보는 입력하지 마세요.

## 실행

```powershell
python -m http.server 8000
```

브라우저에서 `http://localhost:8000/index.html`을 열고, 관리자 목록은 `http://localhost:8000/admin.html`에서 확인합니다.

문의는 같은 브라우저의 `todayfit_inquiries_v1` 키에 저장됩니다. 다른 기기와 공유되지 않으며 관리자 인증도 없습니다. 실제 서비스에서는 인증이 있는 서버 API와 데이터베이스로 교체해야 합니다. 문의 동의 문구는 교육용 예시입니다.

상담 운영 시간·주소와 이미지 속 인물 및 장소는 모두 가상 예시입니다.
